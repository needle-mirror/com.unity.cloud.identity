# Prerequisites

Before you start using the Unity Cloud Identity package, make sure you meet the following prerequisites.

## System requirements

* A valid [Unity ID account](https://id.unity.com/) to generate an identifier for your application

## Compatibility

The Unity Cloud Identity package is compatible with Unity version of 2022.3 or later. This package is also compatible with the following Unity Cloud packages:

* [Unity Cloud Common](https://docs.unity3d.com/Packages/com.unity.cloud.common@1.0)
* [Unity Cloud Assets](https://docs.unity3d.com/Packages/com.unity.cloud.assets@latest)

## Supported platforms

* Windows Standalone
* Android
* macOS 
* iOS: Requires an Xcode project build and a valid development build certificate to achieve binding for the custom URI scheme at the OS level.
